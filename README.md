## Features

1. **CRUD Operations**: AmazeKart provides a powerful admin panel to manage products. Admins can perform CRUD (Create, Read, Update, Delete) operations on products, making it easy to add new products, update existing ones, or remove items from the inventory.

2. **Admin Panel**: The project includes a dedicated admin panel that allows authorized users to manage the entire e-commerce platform. Admins can add/edit products, view and manage customer orders, and gain valuable insights into sales and performance.

3. **Search Functionality**: The search functionality enables users to quickly find products based on keywords or specific attributes. The search feature is intuitive and provides relevant results in real-time, enhancing the user experience.

4. **Authentication**: AmazeKart implements user authentication, allowing users to create accounts, log in securely, and manage their profiles. This ensures that only authenticated users can place orders, view order history, and access personalized features.

5. **Shopping Cart Feature**: Users can add products to their shopping cart, modify quantities, and proceed to checkout to place orders. The shopping cart feature provides a seamless shopping experience, saving selected items even if the user navigates to other pages.
   
7. **Order Progress Tracker**: Once a user places an order, they can track the progress of their order in real-time. The tracker provides updates at various stages, such as order processing, shipment, and delivery. Users can stay informed about their order status, ensuring a transparent and satisfying shopping experience.

## Getting Started

To explore and run the project locally, follow these steps:

### Prerequisites

Make sure you have the following software installed on your system:

- Node.js (at least version 12)
- npm (Node Package Manager) or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/harsh774/next-tailwind-amazekart.git
```

2. Navigate to the project directory:

```bash
cd next-tailwind-amazekart
```

3. Install the dependencies:

Using npm:

```bash
npm install
```

or using yarn:

```bash
yarn install
```

4. Configure the environment:

Create a `.env.local` file in the root directory and add necessary environment variables (if any) as follows:

```
MONODB_URI = something
```

### Usage

To start the development server, run the following command:

```bash
npm run dev
```

or

```bash
yarn dev
```

The application will be available at `http://localhost:3000`.
